# figma-mcp-free Local Bridge Plugin

This directory contains the read-only Figma development plugin for the authenticated local bridge.

## Files

- `manifest.template.json`: tracked least-privilege development manifest.
- `create-manifest.mjs`: inserts the numeric ID generated by Figma Desktop and aligns development network access with the selected bridge port.
- `code.js`: exports selected nodes as `JSON_REST_V1` only after an explicit capture request.
- `ui.html`: pairs with the loopback server and sends one bounded snapshot.
- `manifest.json`: generated locally and intentionally ignored.

## Create the manifest

```bash
node plugins/local-bridge/create-manifest.mjs <FIGMA_GENERATED_PLUGIN_ID> [BRIDGE_PORT]
```

The port defaults to `3845`. Pass the same port used by `figma-mcp-free-bridge serve --port ...` when using a custom port.

Then import `manifest.json` in Figma Desktop as a development plugin.

Do not commit the generated manifest or a pairing token. Do not add remote or wildcard domains. See [the complete bridge guide](../../docs/local-plugin-bridge.md).
